# AI development workspace

This directory is the source of truth for repository-specific AI development context.

- `instructions.md`: stable engineering rules.
- `context.md`: architecture, boundaries, and source-of-truth map.
- `handoff.md`: current implementation status and next work.

Add a skill under `.agents/skills/<name>/SKILL.md` only after a procedure is repeated and verified. Do not scatter AI instructions around the repository.
